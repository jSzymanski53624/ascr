# ВАРТА — сповіщення про повітряну тривогу (Харків)

Переносна програма для Windows 10/11, яка стежить за повітряною тривогою в місті й оголошує її в офісі:
голос через колонки (музика на цей час тихішає), банер поверх вікон, спливаюче вікно Windows і
повідомлення адміністратору в Telegram. Інтерфейс — українською.

**Готова збірка:** [`dist/Varta-portable.zip`](dist/Varta-portable.zip) — розпакувати й запустити `Varta.exe`
(інструкція для користувача — `docs/README_UA.txt`, лежить і всередині архіву).

## Рівні
| Рівень | Значення | Звідки береться |
|---|---|---|
| Червоний | повітряна тривога в місті (або по всій області) | alerts.in.ua (`alert_level=red`), Telegram-канал |
| Жовтий | підвищена загроза: тривога в районі, інші типи загроз, `alert_level=yellow` | alerts.in.ua (рівень), Telegram — лише якщо канал пише про район |
| Зелений | відбій | відсутність активних тривог |
| Сірий | немає свіжих даних | програма **ніколи** не показує зелений, якщо дані застаріли |

Підвищення рівня — миттєве, зниження — після `ClearConfirmPolls` однакових відповідей поспіль.

## Джерела даних
1. **alerts.in.ua** (потрібен безкоштовний ключ, `https://alerts.in.ua/api-request`) — структуровані дані з рівнями й загрозами; ліміт API ≈ 8–12 запитів/хв.
2. **Telegram-канали** (без ключа) — розбір публічної сторінки `https://t.me/s/<канал>`; за замовчуванням `kharkivlife`.
   Канал, що давно не оновлюється, ігнорується й позначається у «Стані».

Якщо основне джерело недоступне, береться наступне; якщо недоступні всі — стан «невідомий» і сповіщення про проблему (лише текстом).

## Структура
```
src/Varta/Core      чиста логіка без Windows: JSON, налаштування, парсери, рушій рівнів, маршрути сповіщень
src/Varta/Platform  Windows: CoreAudio (приглушення музики), MCI (MP3), автозапуск, HTTP, журнал, опитування, перевірки стану
src/Varta/Ui        WinForms: головне вікно, банер, трей, сторінки налаштувань
tests/Varta.Tests   xUnit (net8.0), компілює Core із джерел; фікстури — реальні сторінки Telegram
tools/              make_icon.py (значок), package.sh (збірка переносимого архіву)
```
Програма таргетить **.NET Framework 4.8** (є у Windows 10/11, нічого встановлювати не треба); один `Varta.exe` без сторонніх DLL.

## Збірка й перевірка
```bash
dotnet test tests/Varta.Tests          # 48 тестів логіки
bash tools/package.sh                  # dist/Varta/ + dist/Varta-portable.zip
uv run --with pillow python tools/make_icon.py   # перегенерувати значок
```
Збірка працює на Linux/macOS/Windows з .NET SDK 8+.

## Що перевірено, а що ні
* Перевірено: логіка рівнів, парсери (на реальних сторінках Telegram), маршрути, розклад — автотестами;
  запуск інтерфейсу, живий зв'язок із Telegram-каналом і відображення стану — під Mono/Xvfb.
* **Не перевірялось на справжній Windows:** відтворення MP3 (MCI), приглушення музики (CoreAudio COM),
  автозапуск (реєстр), спливаючі сповіщення трею, єдиний екземпляр (іменований mutex). Усі ці місця
  обгорнуті обробкою помилок і повідомляють про проблему у «Стані»/журналі; вкладка «Система → Діагностика» збирає звіт.

## Застереження
ВАРТА — допоміжний засіб і не замінює офіційну сирену та державні застосунки. Документація alerts.in.ua
не рекомендує використовувати API для критичної інфраструктури.
