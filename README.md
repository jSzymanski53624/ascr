# ВАРТА — сповіщення про повітряну тривогу (Харків)

Переносна програма для Windows 10/11, яка стежить за повітряною тривогою в місті й оголошує її в офісі:
голос через колонки (музика на цей час тихішає), банер поверх вікон, спливаюче вікно Windows і
повідомлення адміністратору в Telegram. Інтерфейс — українською.

**Готова збірка:** [`dist/Varta-portable.zip`](dist/Varta-portable.zip) — розпакувати й запустити `Varta.exe`
(інструкція для користувача — `docs/README_UA.txt`, лежить і всередині архіву).
**Оновлення вже встановленої:** [`dist/Varta-update.zip`](dist/Varta-update.zip) — лише `Varta.exe`, налаштування й звуки не чіпає.

## Зміни
* **1.0.2** — голос не звучав на ПК, де драйвер MCI для MP3 не завантажується (у журналі: «Неизвестная ошибка при загрузке указанного драйвера
  устройства»), і для всіх подій лунав один запасний сигнал Windows. Тепер MP3/WAV розкодовується самою програмою
  ([NLayer](https://github.com/naudio/NLayer), MIT, вбудовано у `src/Varta/ThirdParty/NLayer`) і відтворюється через `SoundPlayer` (winmm `PlaySound`);
  MCI лишився запасним способом. Якщо файл не відтворився — різкий тривожний сигнал замість дзвінка Windows, а причина видна
  у «Стані» (рядок «Останнє озвучення»), під файлом у «Звуку» та в журналі. Попередній перегляд порожнього рядка «Нагадування» грає файл червоного рівня.
  Виправлено вкладку «Стан»: кнопки дій у списку перевірок були обрізані.
* **1.0.1** — вибір звукового файлу застосовується одразу (раніше потрібно було натиснути «Зберегти» — але це було не головною причиною «старого звуку»);
  панель незбережених змін видно на будь-якій сторінці; під кожним файлом показано, що діє зараз; у «Стані» видно, які файли використовуються,
  а в журналі — який файл відтворено; вибір файлу, який не відкривається, потребує підтвердження; резервний сигнал можна перервати.
* **1.0.0** — перший випуск.

## Рівні
| Рівень | Значення | Звідки береться |
|---|---|---|
| Червоний | повітряна тривога в місті (або по всій області) | alerts.in.ua (`alert_level=red`), Telegram-канал |
| Жовтий | підвищена загроза: тривога в районі, інші типи загроз, `alert_level=yellow` | alerts.in.ua (рівень), Telegram — лише якщо канал пише про район |
| Зелений | відбій | відсутність активних тривог |
| Сірий | немає свіжих даних | програма **ніколи** не показує зелений, якщо дані застаріли |

Підвищення рівня — миттєве, зниження — після `ClearConfirmPolls` однакових відповідей поспіль.

## Джерела даних
1. **alerts.in.ua** (потрібен безкоштовний ключ, `https://alerts.in.ua/api-request`) — структуровані дані з рівнями й загрозами; ліміт API ≈ 8–12 запитів/хв.
2. **Telegram-канали** (без ключа) — розбір публічної сторінки `https://t.me/s/<канал>`; за замовчуванням `kharkivlife`.
   Канал, що давно не оновлюється, ігнорується й позначається у «Стані».

Якщо основне джерело недоступне, береться наступне; якщо недоступні всі — стан «невідомий» і сповіщення про проблему (лише текстом).

## Структура
```
src/Varta/Core      чиста логіка без Windows: JSON, налаштування, парсери, рушій рівнів, маршрути сповіщень, розкодування звуку, керування відтворенням
src/Varta/Platform  Windows: CoreAudio (приглушення музики), SoundPlayer/MCI (відтворення), автозапуск, HTTP, журнал, опитування, перевірки стану
src/Varta/ThirdParty/NLayer  декодер MP3 (MIT), вбудований без змін
src/Varta/Ui        WinForms: головне вікно, банер, трей, сторінки налаштувань
tests/Varta.Tests   xUnit (net8.0), компілює Core із джерел; фікстури — реальні сторінки Telegram
tools/              make_icon.py (значок), package.sh (збірка переносимого архіву)
```
Програма таргетить **.NET Framework 4.8** (є у Windows 10/11, нічого встановлювати не треба); один `Varta.exe` без сторонніх DLL.

Службова перевірка звуку (для підтримки): `Varta.exe --audio-test=файл.mp3 [--save-wav=out.wav]` записує `audio-test.txt` поруч із програмою: розкодування, на Windows — ще й реальне відтворення.

## Збірка й перевірка
```bash
dotnet test tests/Varta.Tests          # 98 тестів логіки та розкодування звуку
bash tools/package.sh                  # dist/Varta/, dist/Varta-portable.zip, dist/Varta-update.zip
uv run --with pillow python tools/make_icon.py   # перегенерувати значок
```
Збірка працює на Linux/macOS/Windows з .NET SDK 8+.

## Що перевірено, а що ні
* Перевірено: логіка рівнів, парсери (на реальних сторінках Telegram), маршрути, розклад — автотестами;
  розкодування MP3/WAV — на реальних файлах і типових форматах озвучки (22/24/48 кГц, моно/стерео, VBR, ID3 з обкладинкою, WAV 8/16/24/32 біт):
  результат збігається з ffmpeg (кореляція 1.000000, зсув — стандартна затримка декодера 1105 відліків); керування відтворенням
  (скасування, тайм-аут, «звук завершився миттєво») — на підмінці; запуск інтерфейсу, показ помилок звуку, живий зв'язок із Telegram — під Mono/Xvfb.
* **Не перевірялось на справжній Windows:** сам вивід звуку через `SoundPlayer`, приглушення музики (CoreAudio COM),
  автозапуск (реєстр), спливаючі сповіщення трею, єдиний екземпляр (іменований mutex). Ці місця обгорнуті обробкою помилок
  і повідомляють про проблему у «Стані»/журналі; вкладка «Система → Діагностика» збирає звіт.

## Застереження
ВАРТА — допоміжний засіб і не замінює офіційну сирену та державні застосунки. Документація alerts.in.ua
не рекомендує використовувати API для критичної інфраструктури.
